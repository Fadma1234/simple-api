#  Project:"Abyssinian" information
<img width="1920"  alt="image" src="https://github.com/user-attachments/assets/f730652e-f2cf-468f-86bf-37fed7ec7ae6" />

This project manages the client-side interaction for a simple application that interfaces with The Cat API. An event listener on a button triggers the getPic function, which uses the fetch() API to make a GET request to a specific, hardcoded API endpoint URL. The script then parses the returned JSON data and dynamically updates the webpage by setting the src attribute of an image element to the cat's picture URL, and populating paragraph and heading elements with the cat's description, origin, and height data, demonstrating basic API consumption and DOM manipulation.
